Understanding SpPrAn outputs
===========================

This page is a user-oriented guide to the files and figures produced by SpPrAn.
For each output, it explains what the output represents, how SpPrAn calculates
it, how to interpret it biologically, and which conclusions should not be drawn
from it.

The exact output tree depends on the selected analysis mode and optional
analyses.

----

----

Key concepts
------------

* **Cell type/subtype**: a population defined by user-specified protein marker rules.
* **Discovered phenotype**: an observed binary combination of exploratory protein marker
  positivity states within a user-defined parent population.
* **Protein marker intensity**: the continuous measured signal for a protein marker.
* **Spatial neighborhood**: cells whose tissue coordinates satisfy the
  configured fixed-radius neighborhood rule.

These are different analytical layers and should not be treated as equivalent.

----

----

Where should I look first?
--------------------------

**How many cells of each population do I have?**
   Start with ``results/Cell count report/Cell type proportions report - Sample 
   <ID>.csv`` report for the **Supervised mode**, and also available in the **Unsupervised 
   mode** when "*Full Phenotype Discovery*" (FPD) option is activated. When is not activated,
   start with ``Statistics/results/General/Cell type proportions matrix.csv`` report.

**Where in the tissue are located each population?**
   If the spatial plotting option was configured, use the spatial plots located in the 
   ``plots/<population>`` folders. Here, ``<population>`` refers to ``General`` 
   or **the names of the cell types or subtypes**.

**What fraction of a parent population belongs to a subtype?**
   For the Supervised mode and Unsupervised mode with FPD option, use ``% of parent`` column 
   in the cell-type proportions report.
   For the Unsupervised mode without FPD option, use the ``Statistics/results/Phenotypes 
   proportion/Phenotypes proportion matrix - subtype.csv`` report.

**Which protein marker combinations occur inside a selected parent population?**
   In the Unsupervised mode, use ``Statistics/results/subtype cell proportions/subtype 
   cell proportions - Sample ... .csv`` for discovered phenotypes.
   In the Supervised mode, since all cell types and subtypes were defined by the user, it is 
   known which protein marker combination is occurring inside a parent population. However, 
   it can be consulted in ``results/<population>/All cell type definitions.csv`` reports.

**Does a phenotype proportion differ between two groups?**
   If the option was activated, use the plots located in the ``Statistics/plots/phenotypes 
   differences analysis`` folder together with the ``'Statistics/results/subtype split test 
   analysis/Common subtype proportion differences analysis.csv'`` tables. As a suggestion,
   do not rely only on the plot or on a nominal p-value.

**How strong is protein marker expression inside a discovered phenotype?**
   If protein markers were selected, use the phenotype-specific box-plot/intensity CSVs located in
   the ``Statistics/results/Intensity analysis by phenotype`` folder.
   If "*Advanced phenotype classification*" option was activated, use the advanced classification 
   outputs located in the ``Statistics/results/Advanced cell classification`` folder.

**Where in the tissue is a protein highly expressed?**
   If the protein marker intensity spatial plotting option was activated, use the spatial protein
   marker intensity plots located in the ``plots/Spatial protein markers intensity plots`` folder.

**Which major populations are spatially associated?**
   If the "*Neighborhood analysis*" option was activated, use neighborhood enrichment, interaction 
   matrices, and co-occurrence plots together, located in the ``Statistics/plots/Neighborhood 
   analysis`` folder.

**What can I do if I want to extend or redo the analyses?**
   If *saving the AnnData files* option was set to *Yes*, use the AnnData files located in the 
   ``adata`` folder. Here's a tutorial on how to use AnnData files: 
   `Getting started with anndata <https://anndata.readthedocs.io/en/latest/tutorials/notebooks/getting-started.html>`_.

Shared metadata outputs
-----------------------

``adata/Sample_<ID>.h5ad``
~~~~~~~~~~~~~~~~~~~~~~~~~~

The AnnData file is the reusable single-cell data object generated by SpPrAn.
Depending on the workflow, it can contain:

* continuous protein marker intensities;
* tissue coordinates;
* positivity calls;
* major cell-type labels;
* hierarchical subtype annotations;
* discovered phenotype labels and protein marker patterns;
* neighborhood-analysis results; and
* advanced intensity classifications.

AnnData is a data container. An annotation stored in it reflects the rules and
analyses applied by SpPrAn; it is not independent biological ground truth.

----

``results/Samples Id.csv``
~~~~~~~~~~~~~~~~~~~~~~~~~~

This maps the internal SpPrAn sample ID to the original input filename.

- ``Samples Id``
   Short identifier used in SpPrAn filenames and AnnData files.

- ``Samples filename``
   Original object-table filename.

This is metadata, not a biological result. It is primarily an audit trail for
linking outputs back to source specimens.

----

``results/Positivity column names.csv``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This maps the original Visiopharm positivity columns to the continuous
protein-marker-intensity variables stored in AnnData.

- ``Positivity column names``
   Binary positivity variables used for protein-marker-rule classification.

- ``Name appearing in anndata file``
   Corresponding continuous intensity variable.

A positive/negative call and a continuous intensity measurement are not the same
thing. Positivity defines phenotype membership; intensity describes signal
strength.

----

``results/<population>/Cell type subsets.csv``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This records logical subset relationships inferred from the configured protein marker
definitions.

SpPrAn compares expanded binary protein marker rules to determine whether one definition
is contained within another.

Interpret this as a relationship between **analytical protein marker definitions**.

Do not interpret it as a developmental lineage, differentiation trajectory, or
evidence that one population transforms into another.

----


``results/<population>/All cell type definitions.csv``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This is an audit table of the protein marker rules used for the relevant populations,
including logical/intersection definitions generated during hierarchy
resolution.

It tells the user **how SpPrAn defined a population**. It does not establish
that the protein marker combination is biologically specific in every tissue context.

Supervised mode outputs
-----------------------

``results/Cell count report/Cell type proportions report - Sample <ID>.csv``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This is the main supervised summary of population abundance.

- ``Sample``
   Sample identifier.

- ``Population``
   Major cell type or subtype.

- ``Parent population``
   Immediate analytical parent.

- ``Count``
   Number of cells assigned to the population.

- ``% of parent``
   ``Count / number of cells in the immediate parent population`` expressed as percentage.

- ``% of total``
   ``Count / total cells in the sample`` expressed as percentage.

These percentages answer different questions. A subtype can represent a large
fraction of its parent while remaining rare in the whole tissue.

Use ``% of parent`` for within-lineage/compositional questions and ``% of
total`` for tissue-wide abundance.

Do not infer recruitment, proliferation, survival, differentiation, or function
from a proportion alone.

----


``results/<population>/Cell type proportions - Sample ... .csv``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The columns are cell populations. The two main rows are:

- ``Total cells in cell type``
   Number of cells assigned to each displayed population.

- ``Percentage``
   Percentage relative to the current analytical universe.

.. note::
   For ``General``, the denominator is all cells in the sample. For a subtype 
   folder, the denominator is the parent-population size.

Do not compare percentages from different hierarchy levels without checking
their denominators.

----

``plots/Cell phenotype hierarchy.png``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This visualizes the configured supervised hierarchy and associated protein marker
rules.

The parent-child structure represents nested analytical definitions, not
pseudotime or biological lineage.

----

Supervised spatial population plots
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Overview plots show all configured populations at their measured tissue
coordinates. Highlight plots emphasize one selected population against the
remaining cells.

These plots are useful for visualizing infiltration, compartmentalization,
clustering, and exclusion patterns.

Visual proximity is descriptive. It is not itself a statistical neighborhood
result and does not establish cell-cell communication.

----

--------------------------------------------------------------------------------------------------------------------

Unsupervised mode outputs
-------------------------


``Statistics/results/General/Cell type proportions matrix.csv``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Rows are samples and columns are major populations. Values are the percentages
calculated from the sample-specific proportion tables.

This is useful for comparing broad composition among specimens.

Because the values are compositional, an increase in one population can occur
partly because another population decreased. This matrix is not an absolute
cell-density measurement unless sampled area/cell recovery are independently
accounted for.

----

Pie plots
~~~~~~~~~

Path:

``Statistics/plots/General/pie_plots/``

Pie plots are visual representations of the same composition used in the
proportion matrices.

They are descriptive graphics, not statistical tests.

----


``Statistics/results/sub<cell_type_name> cell proportions/sub<cell_type_name> cell proportions - Sample ... .csv``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The columns are:

- ``Phenotype``
   Machine-readable discovered phenotype.

- ``Total cells``
   Number of parent-population cells assigned to the phenotype.

- ``Proportion``
   Percentage of the selected parent population represented by the phenotype.

- ``Markers name``
   Human-readable protein-marker-pattern description.

SpPrAn encodes each selected parent cell's exploratory-protein-marker positivity pattern
and groups identical observed patterns. The proportion denominator is the parent
population, not all cells in the tissue.

.. _detection_filter:
.. important::
   The default **detection filter** keeps non-zero phenotypes with a within-parent 
   proportion of at least 0.5%.

A discovered phenotype is not automatically a novel biological cell type.
Rare patterns can reflect biology, sampling, positivity thresholds,
segmentation, or technical variation.

----


``Statistics/results/Phenotypes proportion/Phenotypes proportion matrix - sub<cell_type_name>.csv``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Rows are discovered phenotypes and columns are samples. Values are numeric
within-parent percentages derived from the per-sample phenotype tables.

A high value means that the phenotype is abundant **within the selected parent
population**, not necessarily within the tissue as a whole.

Two-group phenotype comparison
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. important:: 
   These outputs are produced when two sample groups are configured.
   A crucial distinction is:

   - ``Detected``: Uses only samples in which the phenotype passed the :ref:`detection filter <detection_filter>`.
   - ``No filter``: Can include zero abundance for samples where the phenotype did not pass the :ref:`detection filter <detection_filter>`.

   These summaries answer different biological questions and should not be mixed.


``Statistics/results/sub<cell_type_name> split test analysis/Common sub<cell_type_name>.csv``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Rows are the phenotypes detected in both configured groups.

Key columns include:

- ``Detected <Group> average %``
   Average phenotype proportion among samples where the phenotype was detected.

- ``Detected Difference <Group 2>-<Group 1>``
   Difference between detected-only group averages.

- ``Interpretation``
   Direction-only text such as increase/decrease.

- ``Detected Sample Frequency in <Group>``
   Number/frequency of group samples where the phenotype was detected.

- ``Detected <Group> Proportion Values``
   Individual detected-only sample proportions.

- ``No filter <Group> average %``
   Broader average that can include zero abundance for non-detected samples.

The ``Interpretation`` column does **not** indicate statistical significance.

----

``Statistics/results/sub<cell_type_name> split test analysis/Unique sub<cell_type_name> - <Group>.csv``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Rows are the phenotypes observed in one configured group but not the
other under the :ref:`detection filter <detection_filter>` rule.

The columns are:

- ``Phenotype``
   Human-readable protein-marker-pattern description.

- ``Detected average %``
   Average phenotype proportion among samples where the phenotype was detected.

- ``No filter average %``
   Broader average that can include zero abundance for non-detected samples.

- ``Condition``
   Group's name.

- ``Detected Sample Frequency``
   Number/frequency of group samples where the phenotype was detected.
   
"Unique" does not mean biologically exclusive to that condition. Non-detection 
can reflect sample size, low abundance, filtering, or technical variation.

----

``Statistics/results/sub<cell_type_name> split test analysis/Common sub<cell_type_name> proportion differences analysis.csv``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This table contains statistical comparisons of common phenotype proportions.
Rows are the same as in ``Common sub<cell_type_name>.csv`` file.

Key columns are:

- ``<Group> (mean ± SD)``
   Mean value and Standard Deviation of the detected-only sample proportions in the group.

- ``<Group> (median [IQR])``
   Median value and the Interquartile Range (IQR) of the detected-only sample proportions 
   in the group. The interval ``[Q1-Q3]`` is composed by the values First Quartile and the 
   Third Quartile.

- ``Mann-Whitney p-value``
   Nominal two-sided Mann--Whitney U p-value.

- ``Raw p-value``
   In the current implementation, this is the nominal **Welch t-test** p-value.

- ``FDR-corrected M-W p-value``
   Benjamini--Hochberg-adjusted Mann--Whitney p-value.

- ``FDR-corrected RAW p-value``
   Benjamini--Hochberg-adjusted Welch t-test p-value.

The tests use the detected-only phenotype-proportion values for the common
phenotype.

Empty values in ``p-value`` and ``FDR-corrected`` columns mean there was no enough data to 
apply the tests.

Interpret nominal p-values together with sample-level values, detection
frequency, effect magnitude, biological sample size, and FDR-adjusted p-values.

Do not treat individual cells from one tissue as independent biological
replicates. The biological replicate for this comparison is the specimen/sample.

Phenotype-difference plots
^^^^^^^^^^^^^^^^^^^^^^^^^^

Path:

``Statistics/plots/phenotypes differences analysis/``

These plots show sample-level detected phenotype proportions and nominal test
annotations.

Use them with the statistical CSV located in the ``Statistics/results/sub<cell_type_name> 
split test analysis/`` folder, especially the FDR-adjusted results.

Phenotype-specific continuous intensity outputs
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


``Statistics/results/Intensity analysis by phenotype/<sample>/Phenotype mapping - Sample <ID> - sub<cell_type_name>.csv``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This table contains the compacted phenotype IDs that are used in the intensities filenames 
to avoid filename-length problems. Rows are the phenotypes detected in the population.

- ``Phenotype ID``
   Compact file-safe identifier such as ``subCellType_P001``.

- ``Phenotype``
   Full protein-marker-defined phenotype name.

Always use this mapping when interpreting compact phenotype IDs.

----

``Statistics/results/Intensity analysis by phenotype/<sample>/<cell_type_name>/Box plot data - Sample ... - <Phenotype ID> (<N> cells).csv``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This tabel contains Tukey box-plot summary values for the phenotype.

Rows are:

* ``Lower_Whisker``
   Represents the lower spread of the data values extending down from the bottom of the 
   central box.

* ``Q1``
   The First Quartile is the 25th percentile, or the median of the lower half of the data.

* ``Median (Q2)``

* ``Q3``
   The Third Quartile is the 75th percentile, or the median of the upper half of the data.

* ``Upper_Whisker``
   Represents the upper spread of the data values extending up from the top of the central 
   box.

Protein-marker columns contain the corresponding intensity statistics. 

.. note::
   In v0.3.2, only protein markers that are **positive in the discovered phenotype 
   definition** are included.

SpPrAn calculates Q1 and Q3, then ``IQR = Q3 - Q1``. Whisker bounds are based on
the conventional 1.5-IQR rule, and the reported whiskers are the most extreme
observed values that remain within those bounds.

Therefore, whiskers are not necessarily the absolute minimum and maximum.

These files are descriptive. They do not perform a statistical comparison of
intensity between groups or phenotypes.

----


``Statistics/results/Intensity analysis by phenotype/<sample>/<cell_type_name>/Intensity data - Sample ... - <Phenotype ID> (<N> cells).csv``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This contains the complete cell-level continuous intensity values for the
phenotype's positive protein markers.

Rows correspond to phenotype cells; columns correspond to the included protein
intensities.

.. note::
   In v0.3.2, only protein markers that are **positive in the discovered phenotype 
   definition** are included.

These data can support custom visualizations or downstream analyses.

Do not treat the many cells from a single specimen as many independent
biological replicates.

Spatial protein-intensity plots
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Path:

``plots/Spatial protein markers intensity plots/<sample>/``

Each cell is plotted at its tissue coordinate and colored by continuous protein
intensity for one marker.

The current implementation scales each sample/protein marker independently using that
plot's observed minimum and maximum.

These plots are useful for identifying within-sample gradients and spatial
compartments.

.. note::
   The same color in two different sample panels does **not** necessarily represent 
   the same absolute intensity.

Advanced phenotype-classification outputs
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. important::
   Advanced classification preserves the original positivity-defined phenotype and
   then classifies the intensity of each protein marker that is positive in that phenotype.

   Within each sample and marker:

   * below the positive-cell 25th percentile -> ``Low``;
   * 25th through 75th percentile -> ``Medium``;
   * above the 75th percentile -> ``High``.

   These categories are sample-relative.


``Statistics/results/Advanced cell classification/Protein marker intensity summary.csv``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Key columns include sample, parent cell type, phenotype, protein marker, total
phenotype cells, low/medium/high cell counts, and low/medium/high proportions.

Each row in the table is a present protein marker in its corresponding phenotype and the 
values are those related to such protein marker.

This table answers the question: **"Among cells already belonging to this phenotype, how is this
positive marker's intensity distributed relative to this sample?"**

----


``Statistics/results/Advanced cell classification/Intensity profiles analysis.csv``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This records observed combinations of low/medium/high states across the
phenotype's positive protein markers.

Key columns are:

- ``Intensity profile``
   Combined profile such as ``MarkerA:High | MarkerB:Medium | MarkerC:Low``.

- ``Total cells in the profile``
   Number of phenotype cells with that combination.

- ``Percentage (%)``
   Percentage of the phenotype represented by that profile.

These profiles describe within-phenotype intensity heterogeneity. They are not
automatically stable functional cell states.

----


``Statistics/results/Advanced cell classification/Phenotype intensity summary.csv``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Important columns include:

- ``Total cells``
   Cells in the phenotype.

- ``Total of positive protein markers in the phenotype``
   Positive protein markers defining the phenotype.

- ``Total of observed profiles``
   Distinct low/medium/high combinations observed.

- ``Most common profile proportion (%)``
   Percentage of phenotype cells belonging to the most frequent profile.

The number of observed profiles depends on both cell count and number of
positive protein markers. It should not be treated as a stand-alone biological
heterogeneity score.

Fixed-radius neighborhood outputs
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. important::
   Neighborhood analysis uses major cell-type labels to produce a spatial connectivity graph.

   The graph fixed radius is ``configured neighborhood radius / pixel conversion rate``. Then, 
   two distinct cells in the sample are *connected* when their Euclidean distance falls within 
   the selected radius.


Interaction matrix heatmaps
^^^^^^^^^^^^^^^^^^^^^^^^^^^

The interaction matrix quantifies the number of connections between cells belonging 
to different annotated populations. It is a descriptive statistic of the spatial graph.

The heatmaps derived from the matrix represents **interaction proportions on the spatial 
graph**. Higher proportions can partly reflect higher population abundance.

.. caution::
   In v0.3.1, interaction matrix heatmaps show interaction counts.

A large interaction proportion does not by itself imply preferential biological
interaction.

Interaction matrix analysis generates heatmaps located in the ``Statistics/plots/Neighborhood analysis/<sample>`` 
folder.

Files are ``Interaction matrix - Sample <ID>.png`` plus one highlighted view per major 
population.

The interaction matrix answers the question: **"How many spatial connections exist 
between different cell populations?"**

----

Neighborhood enrichment plots
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

The neighborhood enrichment analysis compares connections between two cell 
populations against a randomized distribution of cell-type labels and reports a z-score.

- **Positive z-score**: More connections than expected under randomized cell labels.

- **Negative z-score**: Fewer connections events than expected.

- **Near zero**: Little relative enrichment/depletion.

A positive score does not prove direct physical interaction, signaling, or
causal communication.

The diagonal is particularly useful for identifying *homotypic enrichment* 
(connections between cells of the same type), and off-diagonal entries 
describe *heterotypic enrichment* (connections between different cell types).

Neighborhood enrichment analysis generates heatmaps located in the ``Statistics/plots/Neighborhood analysis/<sample>`` folder.

Files are ``Neighborhood enrichment analysis - Sample <ID>.png`` plus one highlighted 
view per major population.

The neighborhood enrichment heatmaps answer the question: **"Are the spatial connections more 
or less frequent than we would expect if cell identities were randomly distributed over the 
same spatial network?"**

----

Co-occurrence plots
^^^^^^^^^^^^^^^^^^^

The co-occurrence analysis measures whether two cell populations are found near 
each other more or less frequently than expected from their overall spatial frequencies.

The co-occurrence analysis computes a distance-dependent ratio:

.. math::

   \frac{P(\text{evaluated population | reference population at a distance }r)} {P(\text{evaluated population at a distance }r)} 

where:

- :math:`P(\text{evaluated population | reference population at a distance }r)` measures how frequently evaluated population cells occur around reference population cells inside a neighborhood of radius :math:`r`.
- :math:`P(\text{evaluated population at a distance }r)` measures how frequently evaluated population cells occur inside a neighborhood of radius :math:`r`.

The interpretation of the co-occurrence ratio is:

- **Ratio > 1**: Relative enrichment around the reference population at a distance :math:`r`.

- **Ratio < 1**: Relative depletion.

- **Ratio = 1**: No relative enrichment.

Co-occurrence is distance-dependent and does not establish causal interaction.

Co-occurrence analysis generates line plots located in the ``Statistics/plots/Neighborhood analysis/<sample>`` folder.

Files are ``Co ocurrence analysis - Sample <ID> - <cell_type_name>.png``. Each plot includes 
a reference line at ratio = 1.

The co-occurrence plots answer the question: **"How does relative association 
between cell populations change with spatial distance?"**

Full mode outputs
-----------------

When "*Full Phenotype Discovery*" (FPD) option is activated in the Unsupervised mode, 
SpPrAn first runs unsupervised phenotype discovery, then
turns discovered protein marker patterns into subtype definitions and continues through
the supervised workflow.

A full-mode run can therefore produce outputs from both major sections above.

What SpPrAn can and cannot establish
------------------------------------

SpPrAn **can** support conclusions such as:

* a protein-marker-defined population was more or less abundant;
* a subtype represented a given fraction of its parent;
* specific protein marker combinations were observed;
* a phenotype was detected in more samples from one group;
* sample-level phenotype proportions differed between groups;
* protein marker intensity showed a spatial pattern;
* positive protein markers showed relative intensity heterogeneity within a phenotype;
* major populations showed spatial enrichment/depletion or distance-dependent
  co-occurrence.

SpPrAn alone generally **cannot** establish:

* developmental lineage;
* differentiation direction;
* causal cell-cell communication;
* ligand-receptor signaling;
* functional activation;
* treatment mechanism;
* absolute cross-sample intensity equivalence without harmonization;
* biological novelty of every marker combination; or
* independence of individual cells as biological replicates.
